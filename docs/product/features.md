# 毛泽东生平时空叙事 3D 地图 — 产品特性文档

## 产品概述

一套**全屏电影级沉浸式**的网页作品，以 3D 立体中国地图为舞台，用"星火燎原"的视觉隐喻，
以时空叙事的方式回顾毛泽东同志波澜壮阔的一生。整体风格**庄重史诗、红色沉浸式**，转场细腻高级。

- **技术栈**：Three.js（CDN）+ 原生 JS/CSS，无框架依赖，单页沉浸体验
- **核心隐喻**：星火（人物生平点位）→ 燎原（红遍九州）→ 鎏金肌理覆盖
- **配色**：庄重红（#8B0000 / #C41E20）+ 烫金（#D4AF37 / #F5D77A），暗调深底

## 六阶段叙事流程

| 阶段 | 名称 | 核心内容 |
|------|------|----------|
| 1 | 开篇入场动画 | 全屏居中展示橘子洲头青年毛泽东形象（占位：SVG 剪影 + 光影），风华正茂远眺山河，暗调静谧，无多余 UI |
| 2 | 目光牵引转场 | 以目光方向为视觉引线，视线向外延展拉伸 → 生成**竖版** 3D 地图 → 镜头翻转放平 → **水平正视带挤出厚度** 3D 地图 → 星火按时间顺序逐个点亮 |
| 3 | 全自动时空漫游 | 镜头按 `eventPoints` 时间顺序自动飞行；每到一个点位：星火高亮跳动 + 悬浮年份标题 + 全局背景切换为该时代氛围 + 悬浮面板展示 brief |
| 4 | 史诗终章特效 | 镜头拉远至全国全景；星火从四面蔓延串联 → 烫金流光肌理覆盖全图 → 外层通透红色光晕包裹 |
| 5 | 解锁自由交互 | 解除锁定；拖拽旋转、滚轮缩放、悬停点位预览事件标题 |
| 6 | 竖向时间轴详情 | 页面向下滚动，地图收束置顶；下方展开竖向生平时间轴；点击节点飞向对应点位并加载详情 |

## 数据模型（eventPoints）

```js
{
  year:     "1893",          // 年份
  name:     "韶山冲",
  location: "湖南湘潭韶山",   // 地点名称
  lat:      27.91,           // 纬度（用于地图定位）
  lng:      112.52,          // 经度
  title:    "诞生",          // 事件标题
  brief:    "……",           // 节点简介（悬浮面板）
  bgDesc:   "……"            // 时代背景描述（用于氛围背景生成）
}
```

## 页面结构

- **全屏 3D 画布层**：Three.js 渲染地图 + 粒子 + 星火
- **氛围背景层**：根据当前时期 `bgDesc` 动态渐变的 CSS 图层
- **叙事 HUD 层**：年份 + 标题悬浮卡、brief 面板、阶段提示
- **时间轴层**：竖向时间轴（阶段 6 展开），点击查阅详情

## 交互设计

- 阶段 1–4：锁屏交互，仅提供「跳过」按钮防止用户被卡住
- 阶段 5+：解锁 OrbitControls（拖拽旋转 / 滚轮缩放 / 悬停预览）
- 阶段 6：鼠标滚轮继续向下滚动即平滑展开时间轴

## 视觉规范

1. 3D 地图采用 GeoJSON 中国轮廓，省份几何体挤出厚度，柔和环境光，哑光质感
2. 全部镜头动画使用缓动函数，节奏舒缓史诗感
3. 星火点亮、燃烧蔓延、鎏金覆盖粒子特效细腻
4. 全屏自适应，窗口 resize 自动适配画布
5. 图片素材预留占位，背景先用渐变 + 图形做氛围
