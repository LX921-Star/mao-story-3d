# 组员本地修改与合并操作卡

> 每人一张卡，照着做即可：拿到源码 → 本地跑起来看效果 → 改完交回来合并。

---

## 第 0 步：拿到源代码并解压

负责人会给你 `源代码-毛泽东生平时空叙事.zip`（约 440KB）。
解压到一个**路径里没有中文和空格**的文件夹，例如 `D:/work/mao-story`。

⚠️ 每个人解压到**自己的文件夹**，不要共用同一个目录。

---

## 第 1 步：装环境（每人一次，约 10 分钟）

| 装什么 | 去哪下 | 验证命令 |
|---|---|---|
| Node.js 18+（LTS 版） | https://nodejs.org | 终端输入 `node -v` 有版本号 |
| VS Code（推荐编辑器） | https://code.visualstudio.com | — |

> Windows 用户建议用 VS Code 内置终端（菜单 终端 → 新建终端）执行下面的命令。

## 第 2 步：装依赖并本地跑起来

在项目文件夹里打开终端：

```bash
cd frontend
npm install        # 首次约 2-5 分钟，只装一次
npm run dev        # 启动本地预览
```

终端会显示类似：

```
  ➜  Local:   http://localhost:5173/
```

浏览器打开这个地址 → 看到片头 → **这就是你自己的预览环境**。
**改代码后保存，页面自动刷新**，随时看效果，不影响别人，也不影响线上网站。

---

## 第 3 步：修改你想改的内容

| 想改 | 打开这个文件（都在 `frontend/src/` 下） |
|---|---|
| 事件、年份、简介、地点 | `data/eventPoints.ts` |
| 颜色（金/红/底色） | `styles/epic.css`（最前面 20 行左右） |
| 片头文字 | `three/NarrativeUI.ts`（搜"恰同学少年"） |
| 播放节奏 | `three/NarrativeController.ts`（搜 PACES） |

改完保存，浏览器里立刻能看到效果，**自己满意为止**。

---

## 第 4 步：改完后怎么"合并"（两种方式）

### 方式 A：有 Git 仓库（推荐，人多时用）

如果负责人已建好 Git 仓库（见《README-部署到GitHub.md》）：

```bash
# 1. 同步最新代码
git pull origin main

# 2. 新建自己的分支
git checkout -b 你的名字/改了什么

# 3. 提交改动
git add .
git commit -m "修改了xx事件的简介"

# 4. 推送并发起合并请求（Pull Request）
git push origin 你的名字/改了什么
```

然后在仓库网页上点 **Pull Request → 创建**，负责人审核后合并，网站自动更新。

> 合并时如果两人改了同一个位置，Git 会提示冲突——不要慌，冲突只在**两个人都改过的那几行**，手动保留想要的版本即可（VS Code 有"接受当前/接受传入"按钮）。改之前先 `git pull`、改动前建分支，可以把冲突概率降到几乎为零。

### 方式 B：没有 Git（人少、改动少时用）

1. 每人只改**分配给自己的文件**（比如 A 只改 `eventPoints.ts`，B 只改 `epic.css`）；
2. 改完把这个文件**发给负责人**（微信/邮件均可），注明"基于 10 月 10 日的版本"；
3. 负责人收到后逐个替换、本地跑一遍看效果、再合并进主版本；
4. 负责人把合并后的**新 zip** 发回群里，每人覆盖自己的文件夹继续。

> 方式 B 的纪律：**一个文件同时只有一个人改**，就永远不会冲突。

## 常见问题

| 问题 | 解决 |
|---|---|
| `npm install` 卡住/报错 | 确认 Node ≥ 18；删掉 `node_modules` 文件夹重试；公司网络受限可 `npm config set registry https://registry.npmmirror.com` 后重试 |
| 页面白屏 | F12 看 Console 红字；确认用 Chrome/Edge 最新版 |
| 5173 端口被占用 | 终端会自动换端口，用终端里显示的新地址 |
| 改坏了想恢复 | 没提交过：删掉文件重新解压覆盖；有 Git：`git checkout -- 文件名` |
| 想知道改了什么 | VS Code 左侧"源代码管理"面板能看到所有改动（红色/绿色对比） |
