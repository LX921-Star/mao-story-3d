# 改内容速查表（给组员）

> 不用装任何软件，在**浏览器里**就能改。找到下面对应的文件，点**铅笔图标 ✏️** 修改，改完点最下面的 **Commit changes** 即可。
> 网站会在 1–2 分钟后自动更新。

---

## 一、我要改「历史事件」（最常用）

**文件**：`frontend/src/data/eventPoints.ts`

这个文件里是一串事件，每个长这样：

```ts
{
  year: '1893',                          // 年份
  name: '韶山冲',                        // 地图上的标记名（短）
  location: '湖南湘潭韶山冲',             // 完整地点名
  lat: 27.91, lng: 112.52,               // 经纬度（定位用，一般不用改）
  title: '诞生',                         // 事件标题
  brief: '1893年12月26日，诞生于……',      // 节点简介（悬浮面板正文）
  bgDesc: '湘中丘陵，青瓦农舍……',         // 时代氛围描述
},
```

### 常见改动示例

| 我想做 | 怎么改 |
|---|---|
| 改某个事件的年份 | 改 `year: '1893'` 里的数字 |
| 改事件标题 | 改 `title: '诞生'` 里的文字 |
| 改事件简介 | 改 `brief: '……'` 里的文字（可写长一点） |
| 改地图上的地点名 | 改 `name: '韶山冲'` |
| 改时代氛围 | 改 `bgDesc: '……'` |
| **新增一个事件** | 复制一整段 `{ ... },`，粘在合适位置，改内容（注意保持逗号） |
| **删除一个事件** | 把对应的 `{ ... },` 整段删掉 |

> ⚠️ 注意：**不要动** `lat` / `lng` 后面的数字，否则标记会跑偏。改完检查每段最后的 `,` 和花括号 `}` 还在。

## 二、我要改「颜色」

**文件**：`frontend/src/styles/epic.css` — 看**最前面第 20 行左右**

```css
--epic-gold: #e8c86a;          /* 主金色 */
--epic-gold-bright: #f7e2a0;   /* 亮金色（标题） */
--epic-gold-soft: #d9c08a;     /* 柔和金（正文） */
--epic-red: #c41e20;           /* 主红色 */
--epic-red-deep: #7a1418;      /* 深红 */
--epic-ink: #08060a;           /* 底色（近黑） */
```

改颜色就是改 `#e8c86a` 这个色号。想换颜色可以到这个网站挑：https://www.colorhunter.com（选一个，复制它的 `#xxxxxx`）。

| 我想做 | 改哪一行 |
|---|---|
| 金色变得更深/更暖 | `--epic-gold` |
| 标题颜色 | `--epic-gold-bright` |
| 红色更鲜艳 | `--epic-red` |
| 背景更黑 | `--epic-ink` |

## 五、改完怎么提交

1. 在网页里改完文字 → 拉到页面**最底部**
2. 在 **Commit changes** 的标题框里写一句说明，例如：`修改韶山冲的简介`
3. 点绿色按钮 **Commit changes**
4. 如果是直接改的 `main` 分支，**1–2 分钟后网站自动更新**；刷新线上网址即可看到

> 如果负责人要求走「分支 + 合并请求」，则别直接提交到 main，改成新建分支，然后点 "Create Pull Request" 请负责人审核。

---

## 六、改坏了想还原怎么办

在仓库的 **History / 提交历史** 里，找到改坏之前的那次提交，点 **Revert**（还原）即可回退，不用担心改坏。
